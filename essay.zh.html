摘要

本文讨论把矩形精确剖分为有限个正方形的经典问题，并把它与本项目所采用的实时构造算法并置考察。我们首先回顾 Dehn 的可解性定理——长宽比为有理数当且仅当存在有限正方形剖分——并用欧几里得算法与连分数给出构造性一半；继而引入 Brooks–Smith–Stone–Tutte 的 Smith 图，把剖分翻译为单位电阻网络，得到 Kirchhoff 电流定律、Ohm 定律以及等效电阻 Req = W/H。在回顾 Moroń、Sprague、Duijvestijn 等里程碑之后，文章详细推导本项目的多焦点尺寸场 target(d) = L·clamp(d/R, 0, 1)p、四叉树 LOD、基于 BigInt 的 80 位定点算术、以及基于扫描线邻接图的异色贪心着色，最后给出 24 项自动化断言与复杂度讨论。全文所有插图均为内联 SVG，不依赖任何外部资源。

关键词：正方形剖分矩形；连分数；Smith 图；电网络类比；四叉树 LOD；定点高精度；图着色；完美平方方

1.问题定义与可解性

所谓把一个 W × H 的矩形作正方形剖分（squared rectangle），是指用有限个两两内部不相交、边长分别为 s1, …, sn 的正方形把该矩形完全覆盖：既不留空隙，也不相互重叠。若所有 si 互不相同，称为完美（perfect）剖分；若剖分中不存在一个由若干方块组成、且自身也是被剖分的真子矩形，则称为简单（simple）剖分，反之称为复合（compound）。这些术语刻画的是剖分的组合结构，而非它的面积。

任何剖分首先必须满足面积守恒：各小正方形面积之和恰等于外框面积。以 W、H 表示外框的宽与高，有

(1.1)Σi=1n si2 = W · H.

这是一个必要条件，却远非充分：它只约束了面积这一阶矩，对边界究竟如何拼接毫无约束。事实上，满足式 (1.1) 的整数多重集不计其数，能真正铺成矩形的却极少。

真正的可解性判据由 Dehn 于 1903 年给出：矩形可作有限正方形剖分，当且仅当其长宽比是有理数。

(1.2)WH ∈ ℚ  ⟺  ∃ n < ∞, {si} : 矩形被有限个正方形剖分.

充分性方向是构造性的：若 W/H = p/q（p、q 为正整数），把矩形缩放为 p × q 后，用 pq 个单位正方形即可铺满；更「经济」的铺法来自下一章的欧几里得算法。必要性方向则是非构造性的，却异常优美：因 W/H 无理，W 与 H 在 ℚ 上线性无关，故可取一个 ℚ-线性泛函 f 使 f(W) > 0、f(H) < 0；对轴对齐矩形定义可加泛函 Φ = f(宽)·f(高)，它在每个正方形上恒为 f(s)2 ≥ 0，而外框上 Φ = f(W)f(H) < 0，与 Φ 的可加性矛盾。这一「带权面积」正是后来 Dehn 不变量思想的雏形。

若进一步把所有边长同时除以它们的最大公约数，可设

(1.3)gcd(s1, …, sn) = 1,

称为本原（primitive）剖分。Conway 等人研究的 Mrs. Perkins's Quilt 正是要求 gcd 为 1 的整数边长剖分，并追求在给定外框边长下使用最少的方块数；由于式 (1.1) 只约束平方和，本原性把问题化为一个整数规划式的组合搜索。最后，本文反复使用的第三个视角是 Brooks–Smith–Stone–Tutte 的电网络对应：把水平剖分线视作节点、每个方块视作 1 Ω 电阻，剖分问题便转化为一个可解的线性电路问题——第 3 章将严格化这一对应。

2.欧几里得算法与连分数

可解性的构造性一半，几乎就是欧几里得算法本身。给定 a > b > 0，反复作带余除法。用统一的记号 r−1 = a、r0 = b，则

(2.1)rk−1 = qk rk + rk+1,   0 ≤ rk+1 < rk,   rn+1 = 0.

每一步的商 qk 恰好告诉我们要从当前矩形中切掉多少个边长为 rk 的最大正方形：这就是「贪心铺方」。余数为零时算法终止，最后的非零余数即 gcd(a, b)；因此算法终止当且仅当 a/b 为有理数，这与式 (1.2) 遥相呼应。

把带余除法改写成连分数，就得到

(2.2)ab = q0 + 1q1 + 1q2 + ⋯ = [q0; q1, q2, …, qn].

以 3:2 为例：3 = 1·2 + 1，2 = 2·1 + 0，故

(2.3)32 = 1 + 12 = [1; 2]  ⟹  1 个 2×2 方块 + 2 个 1×1 方块 = 3 块,   Σsi2 = 4+1+1 = 6 = 3×2.

若长宽比为黄金比 φ，连分数永不终止：

(2.4)φ = 1 + √52 = [1; 1, 1, 1, …].

由式 (1.2)，φ 无理，故黄金矩形不存在有限正方形剖分；贪心过程会不断产生越来越小的方块，趋向一个无限剖分。截断连分数得到的渐近分数 pn/qn = [q0; …, qn] 满足递推

(2.5)pn = anpn−1 + pn−2,   qn = anqn−1 + qn−2   (p−1=1, p−2=0; q−1=0, q−2=1),

其中 an 记 (2.2) 中第 n 个部分商；此处改记 an，是为了避免与渐近分数的分母 qn 混淆。

且误差被相邻两项分母严格控制：

(2.6)|α − pnqn| < 1qnqn+1 ≤ 1qn2.

对 φ 而言 pn/qn = Fn+1/Fn（斐波那契比），误差以 1/qn2 的速度衰减。这正是图 2 中折线不断收紧、方块尺寸按 1, 1, 2, 3, 5, 8, 13, … 增长的解析解释：连分数既给出了「能否有限剖分」的判据，也给出了「用有理比逼近无理比」的最优速率。

3.Smith 图：剖分与电网络的对应

1936–1940 年间，Brooks、Smith、Stone 与 Tutte 在剑桥把一个纯粹的组合几何问题翻译成了电路理论，这套对应后世称为 Smith 图。给定任一正方形剖分，把每一条水平剖分线（即某个方块上边或下边所在的直线）视作一个节点，并令该节点的电势 V 等于这条线的纵向坐标；把每一个边长为 s 的正方形视作连接其上下两条水平线的一条支路，支路电阻统一取 R = 1 Ω，支路电流 I 取该正方形的边长 s。于是电势差恰为 s、电流恰为 s，Ohm 定律自动成立——几何与电路在此完全重合。

先看守恒律。同一条水平线，被位于其上方的方块与位于其下方的方块各自完整地铺满，两侧的宽度之和都等于 W；把方块边长解释为电流，流入与流出该节点的电流便相等，这正是 Kirchhoff 电流定律：

(3.1)Σk ∈ in(v) Ik = Σk ∈ out(v) Ik  ⟺  Σk Ik = 0   (∀ 节点 v).

而在竖直方向上，沿任一竖直线各段方块的高度累加为外框高度 H；对单个电阻，电势降等于电流乘电阻：

(3.2)V = I · R,   R = 1 Ω  ⟹  ΔV = s = I.

式 (3.1) 来自「同一水平线上宽度和守恒」，式 (3.2) 来自「竖直方向高度和」，二者分别对应电路的拓扑约束与元件约束；任何正方形剖分因此都给出一个满足 Kirchhoff 定律与 Ohm 定律的可解线性网络，反之，一个具有正电流解的 1 Ω 网络也可还原为一个剖分。

把整个网络对外看作一个二端元件，其等效电阻定义为端电压与总电流之比。BSST 证明，在「每个方块 = 1 Ω、电流 = 边长」的归一化下，这个比值恰好等于外框的长宽比：

(3.3)Req = VI = WH.

直观地说：以左右两条边界为端子时，注入的总电流是沿竖直边界累加的 H，端电压是沿水平方向累加的 W，二者相除即得 W/H。当外框为正方形时

(3.4)W = H  ⟹  Req = 1.

项目早期科普里那句「外框为正方形时总电阻为 1」，其实只是式 (3.3) 在 W/H = 1 处的特例；对一般矩形，等效电阻随长宽比连续变化，而不是恒等于 1。（若把网络转置 90°、改以上下边界为端子，则得到互倒值 H/W = 1/Req；两者只差一次源漏取向，本文统一采用 (3.3) 的记号。）

这类比还给出一个有用的阅读方式。在本项目的多焦点剖分里，焦点附近方块又小又密；用 Smith 图的语言说，那里沿每条水平线分布的支路数最多、单位面积内载流支路最密集，也就是电流密度最高的区域。等效电阻 Req = W/H 描述的是整个视口的宏观输运，而局部电流密度刻画了剖分的疏密结构——一宏观一微观，正对应后文尺寸场与 LOD 的分工。

4.完美矩形的里程碑

若进一步要求所有方块边长互不相同，剖分便困难得多，这就是完美剖分。1925 年，波兰数学家 Zbigniew Moroń 给出了第一个完美的（矩形）正方形剖分：一个 33×32 的矩形，由 9 个边长互不相同的方块组成

(4.0){si} = {18, 15, 14, 10, 9, 8, 7, 4, 1},   n = 9.

它同时是简单的：其中不存在一个由若干方块构成、自身也被剖分的真子矩形。先用式 (1.1) 做一次最朴素的核算：

(4.1)Σsi2 = 182+152+142+102+92+82+72+42+12 = 324+225+196+100+81+64+49+16+1 = 1056 = 33 × 32.

核算修正：33 × 32 = 1056，九个平方和亦为 1056，二者相等。常见的笔误是写成 1089 —— 1089 = 332 是 33×33 正方形的面积，而非 33×32 矩形的面积。本文在写作时据面积守恒逐项核算并修正了这一数值。

图 4 给出了这 9 个方块的精确整数布局（以左上角为原点、单位为 1）：(0,0,18)、(18,0,15)、(18,15,7)、(25,15,8)、(0,18,14)、(14,18,4)、(14,22,10)、(24,22,1)、(24,23,9)；按行逐段检查可见既无空隙也无重叠。由于集合中含有 1×1 方块，gcd(si) = 1，满足本原性；这正是 Conway 所研究的 Mrs. Perkins's Quilt 对整数边长剖分提出的核心条件——不过 MPQ 通常专指外框为正方形的情形，Moroń 的解是矩形。

此后：1939 年 Sprague 构造出第一个完美平方方（perfect squared square），阶数 55、边长 4205；1978 年 Duijvestijn 借助计算机找到阶数最低的简单完美平方方——21 阶、112×112，并证明不存在更低阶的解。附录图 11 给出一个简化的 21 阶结构示意（非精确布局）。这些结果把 §1 的存在性问题推进为一个极值组合问题：在「所有边长互异」「本原」等约束下最小化方块数 n。从 9 块到 21 块，从矩形到正方形，难度跃升的根源在于边界条件从两条独立边变成了一条封闭的回路。

5.多焦点尺寸场算法

与经典问题不同，本项目并不追求一个固定的、块数最少的剖分，而是要在任意缩放层级上实时生成一张「近处极密、远处极大」的剖分。做法是构造一个连续的目标边长场。设世界由 m × n 个边长为 L = 2D 的宏块组成（D 为整数深度，故 L 在二进制下精确），焦点集合为 {fj}，则任一点 p 到最近焦点的距离为

(5.1)d(p) = minj ‖p − fj‖2.

目标边长定义为

(5.2)target(d) = L · clamp(dR, 0, 1)p,   clamp(x,0,1) = min(1, max(0, x)).

这里 R 是影响半径，p > 0 是形状指数（项目默认 p = 2.4，可在 1–5 间调节）。指数越大，曲线在焦点附近越陡、细分越集中；p = 1 时退化为线性场。由于 L = 2D、坐标均为 dyadic，所有方块边长都能被二进制精确表示，为后文的整数网格哈希与邻接判定打下基础。

从宏块出发做四叉细分：对每个候选方块，把中心点代入尺寸场，若同时满足

(5.3)s > 1.35 · target(中心)  且  s · scale > 2.1 · minPx,

则把它等分为四个 s/2 的子方块并递归，否则输出该方块。第一个不等式是几何判据（方块比目标尺寸粗就继续细分）；第二个是屏幕像素判据——若细分后的方块在屏幕上已不足 minPx 像素，再细分只会浪费。scale 是每世界单位对应的屏幕像素数。注意两个判据是「与」关系：像素判据是消融性的安全阀，绝不会反过来在远场制造小方块。

这个构造有一个关键性质：当 d ≥ R 时 clamp(d/R, 0, 1) = 1，于是

(5.4)target(d) = L · 1p = L   (d ≥ R).

而任何方块边长 s 都不超过宏块边长 L，故 s > 1.35·L 永不成立——远端严格不会产生小方块。尺寸场把「细分预算」全部集中在焦点附近，远处保持大块，这正是图 7 中「远端大块 / 近端密块」的直接来源，也是 §9 中断言「远场 target = L」所验证的性质。

四叉分裂不是在原方块旁添加新方块，而是把父块本身划分成四个互不重叠、恰好铺满父块的子块；由归纳法，任意迭代次数后叶节点集合仍精确覆盖整个世界，覆盖率 100%、重叠为 0（由 §9 的 validate 断言验证）。

此外，尺寸场完全在视口局部坐标中求值：判据 (5.3) 中出现的都是 d/R、s/target 这类无量纲比值，尺寸场本身不含任何绝对世界尺度下限——需要绝对尺度的只有 (5.3) 中面向屏幕的第二个判据。因此把 L 与 R 同时缩放、或把整个视口放大，只会等比例地重标尺寸场而不改变剖分形态：这就是尺度不变性，也是下一章 LOD 得以成立的前提。

6.LOD 与近无限放大

「近无限」放大并非真的存储无限层几何，而是按屏幕像素尺寸决定细分深度（level of detail）。生成器只遍历与当前视口相交的宏块：完全落在视口之外的方块直接剪枝，因此任意时刻只生成可见方块。minPx 给出屏幕上的最小方块像素尺寸，(5.3) 中的 s·scale > 2.1·minPx 保证叶块的屏幕尺寸稳定在约 2.1·minPx 附近——这正是 §9 中 109 倍放大下 26,352 个方块全部为 7.45 px 的原因：自适应回退把整幅图锁定在同一细分级别上。

细分不能无限进行，故设有块数上限 maxBlocks（默认 60000）与最大深度 maxDepth（默认 48）。一旦块数触顶，生成器不是截断输出、造成「一半极密、一半被迫大块」的拼接缝，而是把 minPx 乘以 1.8 调粗后整幅重生成，最多重试 7 次；若仍触顶，则以 minPx×3 且无块数上限的方式生成一幅完整但较粗的图。这样整个视口始终维持同一细分级别，画面不会随平移而闪烁或出现密度断层。

复杂度方面，设屏幕像素面积为 A = Wpx·Hpx，若每个叶块至少占约 minPx2 像素，则可见块数满足

(6.1)N ≤ AminPx2 · C,   C = O(1),   Dtree = O(log LminPx / scale).

每个叶块只被访问常数次，生成与绘制为 O(N)；邻接图的扫描线为 O(N log N)（§8）。由于 N 被屏幕像素预算而非世界面积所界定，缩放 109 倍并不会让块数爆炸——它只是把同一个屏幕预算重新分配到更小的世界区域上，这就是「近无限放大」在有限算力下可行的根本原因。

7.高精度：double 的极限与 BigDec 残差

当相机深入 109 倍时，世界坐标的量级达到约 109 ≈ 230，而 IEEE-754 双精度只有 52 位尾数（约 15–16 位十进制有效数字）。此时一个单位最后一位（ULP）为 230−52 = 2−22 ≈ 2.38×10−7 世界单位；更糟的是，屏幕上相邻像素对应两个几乎相等的大数相减，发生灾难性抵消（catastrophic cancellation），有效位可能骤降到只剩几位。表现为方块边缘抖动、坐标漂移，甚至整列方块塌缩成同一像素。

项目用基于 BigInt 的定点数 BigDec 保存相机坐标。取 PREC = 80 位十进制精度，比例因子 SCALE = 1080，实数 x 以整数 X = round(x·SCALE) 存储：

(7.1)PREC = 80,   SCALE = 10PREC = 1080,   X = ⌊x · SCALE⌉ ∈ ℤ.

四则运算都化为整数运算：

(7.2)add(a,b) = a + b,   sub(a,b) = a − b,   mul(a,b) = a · bSCALE,   div(a,b) = a · SCALEb.

加减精确无误差；乘除各引入一次整数除法（截断到 80 位），相对误差小于 10−80，远低于任何可显示的像素尺度。于是 0.1 + 0.2 在 BigDec 中精确等于 0.3（§9 断言），而 40 次锚点缩放后 scale 仍为有限值。

逐块都用 BigInt 绘制太慢，因此采用「double 主值 + 精确残差」的混合策略：把高精度相机中心 cx 拆成双精度主值 cxhi 与 BigDec 残差 cxlo，绘制时

(7.3)screenX = (wx − cxhi) · scale + W2 − offX,   offX = toNumber(cxlo · scale).

其中 wx 是方块世界坐标（由视口局部坐标加主值原点得到），W/2 为屏幕中心，offX 是被 double 主值丢弃的低位在屏幕空间的补偿项。方块主体仍走快速的 double 变换路径，每帧只需少量 BigInt 操作把残差补回，从而在 109 倍放大下像素坐标依旧不漂移——图 9 示意了未补偿与补偿后的差别。速度来自 double，精度来自 BigInt，二者各司其职。

8.邻接图、异色着色与稳定微扰

为了让相邻方块可区分，先要构造共边邻接图。所有方块边长都是同一最小边长 minS 的整数倍（dyadic 坐标），把坐标归一化为整数键后，按同一条分割线把左右（或上下）两侧的区间分别排序，再用双指针线性归并，即可枚举所有共边对：

(8.1)Tbuild = O(n log n)  (排序主导),   |E| = 2n + O(√n).

§9 中 109 倍放大下得到 |E| = 52,366 条邻接边，且扫描线是精确整数归并，不依赖浮点比较，因此在极小尺度下也不会漏边或多边。

着色按边长降序处理（大方块先定色、小方块后补），对每块施加硬约束：任何相邻两块不得取同一调色板索引：

(8.2)c(u) = min { k ∈ P : ∀ v ∈ N(u), c(v) ≠ k },   P = {0, …, 31}.

调色板为 32 色低饱和色，明度限制在 36%–72%、饱和度适中，并显式排除纯黑、纯白与中性灰（§9 断言 minS = 80、minL = 50）。值得一提的是，四色定理只保证「平面图的邻接异色 4-着色存在」，并不给出构造、也不保证视觉上的区分度；本项目用的是更多颜色（32 色）的贪心构造，配合目标色相与稳定微扰，换取稳健且美观的可分辨性。

为让同一方块在 LOD 变化、平移与缩放之间保持颜色稳定，每个方块以其整数网格坐标 (ix, iy, is) 作链式 mix32 哈希：连续三次 32 位雪崩混合，再把两次雪崩结果打包进 53 位整数（253）——这是 double 能精确表示的最大整数范围，故微扰值在任意缩放下都确定、可复现且不坍塌（§9 中 4096 个连续整数坐标的哈希全不重复）。链式混合而非简单异或，是为了避免整数格点上系统性的哈希碰撞。

9.验证与复杂度

项目的 node tests/verify.js 以 24 项断言覆盖上述全部机制，且全部通过（ALL PASS）。几何方面：面积守恒比值 1.000000、零空隙（gaps = 0）、零重叠（overlaps = 0）；深空方面：109 倍放大生成 26,352 个方块，其屏幕尺寸全部为 7.45 px（minPx = maxPx = 7.45 px，说明 LOD 自适应把整幅图稳定在同一细分级别）；着色方面：52,366 条邻接边中同色对为 0（same = 0），低饱和调色板在全视图保持 30 个不同色相、深放大保持 16 个色相桶，且无黑/白/灰填充（minS = 28.0、minL = 43.0）；哈希方面：4096 个连续整数坐标的哈希值互不重复（unique = 4096）。

(9.1)通过断言总断言 = 2424 = 100%,   gaps = overlaps = same = 0,   Σsi2 / (WH) = 1.000000.

数值方面：BigDec 满足 0.1 + 0.2 = 0.3、10−30 × 109 = 10−21，40 次锚点缩放后 scale ≈ 1.413×1011 仍为有限值；尺寸场方面：焦点中心目标尺寸远小于远场（near ≈ 0，far = 256 = L），且远场严格等于宏块边长 L；经典模式方面：euclid 与 network 在 7 种长宽比下都精确铺满整个外框（面积比 1.000000、零空隙），Moroń 九块边长平方和恰为 1056 = 33×32，细分阶数由 0 升至 4 使方块数从 2,638 增至 53,848，44,851 块的密集剖分仍零空隙。这些断言把「宏观正确」与「深空不退化」同时钉死，任何一处回归都会立刻暴露。

复杂度汇总：生成 O(N)，邻接 O(N log N)，着色 O(N·|P|·deg) 但因 deg 有界而近似 O(N)，验证 O(N log N)；N 由屏幕像素预算 (6.1) 而非世界尺度界定。此外在浏览器中通过 CDP 真实设备模拟对 390×844、360×800、844×390、1600×900 四种视口逐一检查，文档均无横向溢出、公式块可横向滚动而不撑破布局——保证 390 px 手机与 1000 px 桌面同样可读。所有断言都可在离线、零依赖的 Node 环境下复现。

补充 B：两种经典模式的全幅覆盖与阶梯细分

除多焦点尺寸场外，项目另提供欧几里得连分数剖分与 Smith 电网络（Moroń 子网络）两种经典模式。由于 world 的比例恰为整数比 m:n，两者的骨架都是对 W×H 的精确辗转相除剖分，因而骨架本身已严格铺满整个外框，不存在只在中央放置一块 33×32 图案、四周留白的情形。network 模式随后按 Smith 图「一个 1Ω 电阻可由一个子网络替换」的思想，把每个骨架方块细分为 33×33 个元胞：上部 33×32 个元胞由 Moroń 的 9 个互异正方形覆盖，最后一行由 33 个单位方块收尾，共 42 个正方形，且仍精确铺满父方块。

进一步的密度由 L 形阶梯细分提供。令 t = s/k（实现取 k = 3），父方块划分为一个 (k−1)t 的大方块、右侧 k 个 t 方块与下侧 k−1 个 t 方块，合计 2k 个正方形；每次替换都是父块的一个划分，因此任意层数后覆盖率仍严格为 1：

(B.1) ((k−1)t)2 + (2k−1)t2 = (k2−2k+1+2k−1)t2 = k2t2 = s2,   nout = 2k.

细分与否只由屏幕像素尺寸 s·scale 与阶数 order 决定：放大时自动展开新层，视口外的块直接剪枝，故方块数可从数百增长到数万而覆盖始终完整。图版 B 依次给出骨架、42 块子网络与 k = 3 的阶梯划分。
